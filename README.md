# 수업 도구함

수업 자료 만들기, 기출 분석, 학생 리포트, 숙제까지 한 사이트·한 로그인에서 쓰기 위한 학원 통합 시스템입니다.
지금 버전: **0단계(기반)** + **내용이해 워크북** + **지문 분석** + **단어장(학생 퀴즈 포함)** + **어법 문제** + **변형문제** + **문장 시험지** + **지문 변형** + **워드 다운로드** + **학생·반 리포트(자동 채점)** + **숙제** + **기출 분석**. 나머지 기능은 단계별로 하나씩 얹습니다.

## 지금 되는 것

| 기능 | 내용 |
| --- | --- |
| 계정 | 원장 가입(학원 등록) → 선생님은 초대 코드로 합류. 아이디 + 숫자 PIN |
| 학원 설정 | 학원 이름, 대표색, 로고 → 모든 PDF 머리말과 화면에 반영 |
| Gemini 연결 | 선생님별 개인 키(암호화 저장), 모델 선택, 연결 확인 버튼 |
| 학생 명단 | 학교·반·학생 관리, 엑셀 명단 붙여 넣기, 퇴원 처리, 명단 PDF |
| 학생 접속 | 학생마다 6자리 접속 코드, 로그인 없이 `/s/코드` 로 입장 (숙제 기능의 입구) |
| 작업 대기열 | 오래 걸리는 작업을 뒤에서 처리, 진행 단계 표시, 서버 재시작 후 이어서 처리 |
| PDF 엔진 | 나눔고딕 · 뉴트럴톤 · 학원 로고 머리말 · 쪽 번호 공통 양식 |
| 메뉴 | 로드맵의 전체 기능이 메뉴에 있고, 아직 없는 기능은 '준비 중'으로 표시 |
| 내용이해 워크북 | 지문 최대 6개 → 지문당 30문항(OX 한글·영어 기본/심화 20, 목표어법 작문 5, 단어 뜻 5) → 문제지·답지 PDF 따로 |

### 기출 분석
- 시험지 PDF(스캔)·사진을 올리면: 쪽 이미지로 바꾸고 → 옆으로 누운 쪽은 tesseract 방향 감지로 바로 세우고(받은 시험지 103쪽 중 문항 있는 쪽 전부 맞음) → 빈 쪽은 건너뛰고 → 2쪽씩 Gemini에 보내 문항을 글자 그대로 옮겨 받음 (학생 필기·동그라미 무시).
- 코드가 하는 것: 쪽을 넘어 이어진 문항 합치기, '서답(서술)형7' 같은 번호 정리, 지문 공유 묶음([1~2], [7, 서답형1]) 연결, 발문으로 유형 분류(규칙 23개, 못 정하면 AI 판단), 번호 빠짐·선지 개수·배점 합계·표지 문항 수 대조 검사.
- 화면: 문항 카드(펼쳐서 고치기, 쪽 이미지와 비교), 유형별 배점, 출제 특징 자동 정리, 쪽 돌리기·고른 쪽만 다시 읽기.
- 출력: 기출 분석지 PDF (요약 1쪽 + 문항별 분석표), '학생·반 리포트로 보내기' (번호·배점·유형이 그대로 들어간 채점용 시험 생성).
- 개발용 가짜 AI(FAKE_LLM=1)는 전라고 2026 1학기 2차 시험지를 사람이 직접 옮긴 실제 데이터(app/exam/fixtures)를 돌려줍니다.
- 다음: 원문 은행(교과서·모의고사·부교재 지문 등록) → 문항별 출처 자동 찾기·변형 분석, 같은 학교 시험이 쌓이면 경향분석.

### 숙제 (AI 없이 동작)
- 할 일 종류: 단어 퀴즈(단어장), OX 퀴즈(내용이해 워크북 OX 복사), 답 입력(종이로 푼 변형문제·어법 문제 시험지, 또는 교재 정답 직접 입력), 할 일 체크(본문 암기 등).
- 통과 점수를 정하면 넘을 때까지 '다시 풀기'로 남음. 비우면 한 번 내면 완료. 마감 뒤에 끝낸 것은 '늦음' 표시.
- 학생은 접속 코드 화면에서 숙제를 보고 폰으로 풀며, 정답은 화면에 보내지 않고 서버가 채점. '정답·해설 보여 주기'를 끄면 틀린 번호만 보여 줌.
- 선생님 화면: 학생 × 할 일 완료 표(칸을 눌러 직접 완료 처리 가능), 할 일별 많이 틀린 문항·단어, 카톡 문구 복사(전체 안내, 못 한 학생별 개인 링크 포함 독촉 문구).
- 카카오 알림톡 자동 발송은 학원 카카오 비즈니스 채널과 발송 대행사 가입 후 연결 예정.

### 학생·반 리포트 (AI 없이 동작)
- 시험 만들기: 객관식·서술형 문항 수, 정답 한 줄(35214… / 복수 정답 2/4), 배점. 유형·출처는 표에서 고치거나 '1-3 어법, 4-6 빈칸'처럼 범위로 한꺼번에.
- 답 받기: 선생님이 학생마다 객관식 답을 한 줄로 입력(Enter로 다음 학생, 맞은 개수 바로 표시), 서술형은 점수 입력. 또는 '학생 제출'을 열면 학생이 접속 코드로 들어가 번호를 눌러 제출(정답은 학생 화면에 보내지 않음).
- 자동 채점·통계: 평균·중앙값·표준편차, 점수 분포, 유형별 득점률, 문항별 정답률·선지 분포·변별도·매력 오답. 정답을 나중에 고쳐도(정답 정정) 바로 다시 채점.
- 학생 화면(선생님용): 나 vs 반 유형별, 틀린 문항(반 정답률 70% 이상인데 틀린 '아까운 문항' 표시), 자동 요약 문장, 선생님 코멘트.
- 출력: 학생별 리포트 PDF(한 명당 한 쪽, 등수 넣기 선택), 반 리포트 PDF(성적표·문항 분석, 이름 가리기 선택), 결과 이미지 PNG(1080px, 단톡방·블로그용), 성적 CSV(엑셀).

### 지문 변형

- 지문 최대 6개, 지문마다 강도 약(8~25%)·중(22~45%)·강(40~75%). 변형도는 원문과 단어 단위로 비교해 프로그램이 계산하고, 범위를 벗어나면 한 번 더 받습니다.
- PDF 앞쪽은 학생용 변형 지문, 뒤쪽은 교사용 원문 대조(지운 부분 취소선, 새로 넣은 부분 밑줄)와 바뀐 표현 표.
- 변형 지문을 직접 고치면 대조·변형도가 다시 계산됩니다. "이 강도로 다시 변형", 워드(대조 포함 / 변형 지문만).
- 규칙은 `app/paraphrase/spec.py`. 나중에 동형 모의고사의 "학교 변형" 지문 만들기에 그대로 씁니다.

### 문장 시험지

- 지문 최대 6개(지문마다 40문장까지) → 유형 4가지: 해석 쓰기, 영작(힌트: 단어 수/첫 단어/없음), 단어 배열, 빈칸 채우기(첫 글자 힌트 + 우리말).
- AI는 문장별 해석과 빈칸 단어만 정하고, 문장 나누기·단어 섞기·빈칸 만들기·순서 섞기는 프로그램이 합니다.
- 결과 화면: 해석·빈칸 단어 고치기, 유형·힌트 바꾸기, "순서·단어 다시 섞어서 만들기"(AI 호출 없음), 계속 실패하는 지문 빼기.
- 정답은 맨 뒤 페이지, 워드로 받기.

### 변형문제 (수능 유형)

- 지문 최대 6개 × 고른 유형마다 1문항: 주제, 제목, 요지, 빈칸 추론, 순서 배열, 문장 삽입, 무관한 문장, 요약문 완성, 내용 일치, 어휘(문맥상 낱말).
- 순서 배열·문장 삽입은 AI 없이 프로그램이 원문을 그대로 잘라 만듭니다 (정답이 틀릴 수 없음). 무관한 문장은 AI가 쓴 한 문장을 프로그램이 끼워 넣습니다.
- 빈칸은 AI가 고른 구절을 프로그램이 지문에서 찾아 빈칸으로 바꿉니다. 규칙에 안 맞는 유형만 다시 요청하고, 끝내 안 되면 그 유형만 빼고 경고.
- 2단 시험지 + 정답·해설 맨 뒤, 워드로 받기, 보기·정답·해설·어휘 밑줄 고치기, 문항 빼기.
- 규칙은 `app/variant/spec.py`.

### 워드(.docx) 다운로드

- 어법 문제, 변형문제, 문장 시험지, 지문 변형, 내용이해 워크북(문제지·답지), 단어장·단어 시험지를 워드로 받을 수 있습니다.
- AI를 다시 부르지 않고 저장된 문항으로 바로 만들어 즉시 받아집니다. 결과 화면에서 고친 내용이 그대로 들어갑니다.
- 나눔고딕, 학원 로고·이름 머리말, 2단 시험지, 답지는 새 페이지. 지문 분석은 색 표시가 많아 PDF로만 제공합니다.

### 어법 문제

- 문장형 5가지(목표어법으로 출제, 유형마다 0~15개): 괄호 선택, 빈칸 5지선다, 문장 고르기(옳은/틀린), 단어 배열 서술형, 문장 전환 서술형.
- 지문형 2가지(지문 최대 3개, 지문마다): 밑줄 5지선다(틀린 것 1개), 어법 개수(틀린 것 1~4개, 정답은 개수와 기호까지).
- 2단 시험지 + 정답·해설은 맨 뒤 페이지. 밑줄 문제 해설에는 틀린 밑줄의 고친 형태와 이유가 붙습니다.
- 배열 문제 단어는 프로그램이 섞고, 밑줄은 AI가 준 구절을 프로그램이 지문에서 단어 경계로 찾아 붙입니다.
- 규칙(보기 5개, 정답 하나, 틀린 밑줄 개수 등)에 안 맞으면 한 번 더 받고, 그래도 안 되는 유형만 빼고 경고로 알려 줍니다.
- 결과 화면에서 모든 문항의 보기·정답·해설·밑줄 정답을 고치거나 문항을 뺄 수 있습니다.
- 규칙은 `app/grammar/spec.py`.

### 단어장

- 만드는 방법 두 가지: 지문에서 단어 뽑기(5~60개) / 단어 목록 붙여 넣기("단어" 또는 "단어 | 뜻", 엑셀 두 칸 그대로).
- 각 단어: 품사·뜻·유의어·반의어·예문(지문 속 문장)·예문 해석. 선생님이 적은 뜻은 AI가 바꾸지 않고, 빈칸만 25개씩 나눠 채웁니다.
- 표에서 바로 고치기, 단어 추가·빼기, "저장하고 빈칸 AI로 채우기".
- PDF: 단어장(전부 보이기 / 뜻 가리기 / 단어 가리기, 예문 넣기), 단어 시험지(영→뜻, 뜻→영, 섞기, 문항 수, 순서 섞기) — 답지는 맨 뒤 페이지.
- 반에 내주기 → 그 반 학생이 접속 코드(`/s/코드`)로 들어와 단어 카드 보기, 퀴즈 4종(영어 보고 뜻 고르기·뜻 보고 영어 고르기·뜻 쓰기·영어 쓰기).
- 퀴즈 정답은 화면에 보내지 않고 서버가 채점합니다. 뜻 쓰기는 여러 뜻 중 하나만 맞아도, 띄어쓰기·물결표가 달라도 정답 처리.
- 선생님 화면에 학생별 점수와 많이 틀린 단어가 쌓입니다.

### 지문 분석

- 지문 최대 6개 → PDF 한 파일. 문장마다 색 표시(문법·어휘·문법+어휘·연결어·구조 강조), 구문 칩, 해석, 출제 포인트(전체 문장의 20~40%).
- 지문 끝: 주제, 흐름, 관련 배경지식, 흐름 상자 그림, 중요 어휘표(단어·의미·유의어·반의어).
- PDF 모양 두 가지: 분석본형(지문 7 : 주석 3) / 분석자료형(1단, 포인트는 문장 아래). 결과 화면에서 바꾸면 AI 호출 없이 다시 만듭니다.
- 문장 나누기는 프로그램이 해서 빠지는 문장이 없고, 색 표시는 AI가 "어떤 단어에 무슨 색"만 주고 프로그램이 칠합니다.
- 해석·칩·포인트·주제·흐름·배경지식·어휘표를 직접 고칠 수 있습니다.
- 규칙은 `app/analysis/spec.py` (기존 analysis · passage-analysis-worksheet 스킬을 합친 것).

### 내용이해 워크북

- 지문마다 제목·목표어법(비우면 공통 목표어법)·한글 해석(비우면 자동 번역)을 넣을 수 있습니다.
- 문제지 지문 칸은 영어:해석 6:4 (7:3, 5:5 선택), 해석·목표어법 표시는 끄고 켤 수 있습니다.
- 작문 문제의 괄호 단어는 AI가 아니라 프로그램이 정답 문장에서 뽑아 섞습니다. 단어가 정답과 어긋날 수 없습니다.
- AI 답이 규칙(문항 수, O/X 값 등)을 어기면 어긴 내용을 알려 주고 한 번 더 받습니다. 그래도 안 되면 그 지문만 실패로 표시됩니다.
- 결과 화면에서 문항을 직접 고치고 'PDF 다시 만들기'(AI 호출 없음), 또는 지문 하나만 새로 만들 수 있습니다.
- 지문 하나가 끝날 때마다 저장하므로 서버가 재시작돼도 남은 지문만 이어서 만듭니다.
- 출제 규칙은 `app/comprehension/spec.py` 에 있습니다 (기존 comprehension-workbook 스킬과 같은 규칙).

## 내 컴퓨터에서 실행

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

브라우저에서 http://localhost:8000 → 계정 만들기.
DB는 `local.db` 파일에 저장됩니다.

Gemini 키 없이 화면만 시험해 보려면 `FAKE_LLM=1 uvicorn app.main:app --reload` 로 실행하세요.
가짜 문제가 만들어집니다. 배포 환경에서는 절대 켜지 마세요.

## Render 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [Neon](https://neon.tech) 또는 [Supabase](https://supabase.com)에서 무료 Postgres를 만들고 연결 주소를 복사합니다.
3. Render → New → Blueprint → 저장소 선택 (`render.yaml` 을 읽습니다).
4. 대시보드 Environment 에서 `DATABASE_URL` 에 2번 주소를 넣습니다.

`DATABASE_URL` 을 비워 두면 Render 무료 서버가 잠들었다 깨어날 때마다 자료가 전부 지워집니다. 꼭 넣으세요.
`SECRET_KEY` 는 Render가 자동으로 만들어 줍니다. 나중에 바꾸면 저장된 Gemini 키를 다시 넣어야 합니다.

## 폴더 구조

```
app/
  main.py         앱 시작, 라우터 연결
  config.py       환경 설정
  db.py models.py DB 연결과 테이블
  security.py     PIN 해시, 키 암호화, 코드 생성
  features.py     전체 기능 목록 = 메뉴 (ready=True 로 바꾸면 메뉴가 열림)
  llm.py          Gemini 호출 공통 엔진 (글자 + 이미지, JSON 응답, 재시도)
  jobs.py         작업 대기열
  pdf.py          PDF 출력 공통 엔진
  handlers/       작업 처리기 (기능마다 파일 하나)
  routes/         화면과 API (기능마다 파일 하나)
  templates/      화면 HTML, templates/pdf/ 는 출력물 양식
  static/         CSS, JS, 나눔고딕 글꼴
```

## 새 기능을 얹는 방법 (1단계부터 이 순서로)

1. `models.py` 에 테이블 추가
2. `handlers/새기능.py` 에 `@job_handler("종류")` 로 오래 걸리는 작업 작성 (Gemini 호출은 `llm.generate`, PDF는 `render_pdf`)
3. `routes/새기능.py` 에 화면 추가, `main.py` 에 연결
4. `features.py` 에서 해당 기능을 `ready=True, path="/주소"` 로 바꾸기
