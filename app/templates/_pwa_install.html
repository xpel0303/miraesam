{{ "미래샘 숙제 앱" if pwa_code else "미래샘 선생님 앱" }} 설치하기홈 화면에 아이콘이 생겨요

아이폰에서 앱으로 설치하기

  1. 사파리 아래쪽 공유 버튼(□↑)을 눌러요
  2. '홈 화면에 추가'를 눌러요
  3. 오른쪽 위 '추가'를 누르면 끝!

카카오톡 안에서 열었다면 오른쪽 아래 ⋯ → '다른 브라우저로 열기(사파리)' 먼저 해 주세요.

안드로이드에서 앱으로 설치하기

  1. 크롬(또는 삼성 인터넷)으로 이 화면을 열어요
  2. 오른쪽 위 ⋮ 메뉴를 눌러요
  3. '앱 설치' 또는 '홈 화면에 추가'를 누르면 끝!

카카오톡·네이버 앱 안에서는 설치가 안 돼요. 크롬으로 먼저 열어 주세요.
